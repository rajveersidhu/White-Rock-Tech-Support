# White Rock Tech Support

A lightweight, responsive website for a local computer repair and technology support business serving **White Rock and South Surrey, British Columbia**.

The site is built as a simple static website using HTML and CSS, making it fast, easy to maintain, and free to host with services such as GitHub Pages.

## Overview

White Rock Tech Support provides local technology assistance for individuals, home offices, and small businesses.

Services highlighted on the website include:

- Computer diagnostics and troubleshooting
- Windows and macOS support
- Virus and malware cleanup
- Wi-Fi and home network setup
- SSD and RAM upgrades
- New computer setup
- Data transfers and backup setup
- Printer and peripheral setup
- Phone and tablet assistance
- General technology support

## Features

- Responsive mobile-friendly layout
- Clear service and pricing sections

## Running the Website Locally

No installation is required.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

For example:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Then open `index.html`.

## Customization

Before publishing the site, update the placeholder contact information in `index.html`.

Replace:

```text
White Rock Tech Support
YOUR_PHONE_NUMBER
YOUR PHONE NUMBER
your@email.com
```

with your actual:

- Business name
- Telephone number
- Email address

You can also update:

- Service descriptions
- Prices
- Service area
- About section
- Meta description
- Page title

## Deploying with GitHub Pages

This website can be hosted for free using GitHub Pages.

1. Create a public GitHub repository.
2. Upload the project files.
3. Open the repository on GitHub.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch.
7. Select `/ (root)`.
8. Save.

GitHub will publish the site at an address similar to:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

A custom domain can be connected later without rebuilding the site.

## Security

Because the website is static, it has a relatively small attack surface compared with websites that rely on server-side applications or databases.

When deployed through GitHub Pages, HTTPS can be enabled for encrypted connections.

Do not commit private information, passwords, API keys, customer records, or other sensitive data to this repository.
