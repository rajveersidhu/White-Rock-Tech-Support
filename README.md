# White Rock Tech Support Website

A simple static website for a local computer repair and tech support business.

## 1. Edit your contact details

Open `index.html` and replace:

- `White Rock Tech Support` with your final business name
- `YOUR_PHONE_NUMBER` with your phone number in international format, e.g. `+16045551234`
- `YOUR PHONE NUMBER` with the human-readable version, e.g. `(604) 555-1234`
- `your@email.com` with your email address

## 2. Upload to GitHub

Create a public GitHub repository, then upload:

- `index.html`
- `style.css`

## 3. Turn on GitHub Pages

Repository → Settings → Pages

Choose:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

Save.

Your site will appear at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
